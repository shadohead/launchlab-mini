# 0.10.7 — Clearer page navigation

Replaces `A view B back` and `A next B back` with `A next page B main` on history/trend, battery, motion/recreate and Settings pages. Tap A cycles the seven pages; tap B returns to the main launch screen. Labels remain muted grey. Button actions and all acquisition/power settings are unchanged. No clock feature. See manifest for validation scope.
