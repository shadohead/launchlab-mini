# Old TCRT5000 / LM393 sensor

This is the older, larger blue analog sensor module, separate from the small QRE1113 build. Use its **analog AO** output and the frozen **0.2.0-sticks3-tcrt5000** firmware. DO remains disconnected. No sensor auto-detection is provided.

| TCRT5000 module | M5StickS3 K150 Hat |
| --- | --- |
| AO | G1 / GPIO1 |
| VCC | 3V3 / 3V3_L2 |
| GND | GND |

Verify your module's physical pin labels. Do not power it from the 5 V Grove red lead or use GPIO0 as the analog input. The old profile uses an 80-count minimum mark and 70% repeated-swing reversal hysteresis at 50 kS/s. The QRE firmware has a different profile.

## Printed mount

[v0.43](../hardware/minimal_TCRT_split_keepers_v043/) is the latest sensor-only CAD prototype: cradle, two separate screw-on clip caps, pressure keeper and both launcher latches. Use 2×M2×4 pan-head screws for the sensor keeper and 2×M2×5 countersunk screws for the clip caps, checking actual preload and engagement after printing. M5 is on a separate carrier. STLs are in manufacturing orientations; preview STLs and STEP files retain assembly poses. There is no saved sliced 3MF for v0.43. Import the six manufacturing STLs, position, slice and inspect them for your printer.

The earlier [v0.19](../hardware/LaunchLab_v019_tcrt5000_open_stack/), [v0.41](../hardware/minimal_TCRT_stack_v041/) and [v0.42](../hardware/minimal_TCRT_sensor_only_v042/) are preserved as historical alternatives. See [all hardware versions](HARDWARE_VERSIONS.md).

## Restore the saved old-sensor application

Download the [old TCRT firmware release](https://github.com/shadohead/launchlab-mini/releases/tag/firmware-tcrt5000-v0.2.0). This is an application-only image for an M5StickS3 K150 that already has the LaunchLab `default_8MB` partition layout. It is not a factory-board first-install bundle. The browser updater currently installs QRE firmware only.

With Espressif esptool installed, enter download mode and replace `YOUR_SERIAL_PORT` with the device's port:

```sh
python3 -m esptool --chip esp32s3 --port YOUR_SERIAL_PORT --baud 460800 \
  write-flash 0x10000 firmware/releases/0.2.0-sticks3-tcrt5000/LaunchLabMini.ino.bin
```

Preserve the bootloader/partitions and verify the device write checksum. The saved image is 619,408 bytes and its SHA-256 is `8f60898d0a4fd3e9e6cf16c741ada3ac50949d21f52ab84574b8c54e09a5dec6`. The runtime version still reads `0.2.0-sticks3-acquisition`; it was not rebuilt or retuned for publication.

The original trial had three user-confirmed pulls, three device detections and three saved-waveform replay results. It is not independent absolute RPM calibration and does not validate the newer printed mounts. This earlier acquisition build does not supply the QRE 0.7.0 history/trend/Motion/Recreate UI shown in the README. Historical READMEs retain development-era commands and private evidence references; those backups and practice captures are not part of the public package. Use this guide for public restore paths.
